Bu projede Page Object Model(POM) ile Cucumber BDD framework kullanılarak 
UI(User Interface) test yapılmıştır. Testin koşturulması için 
TestRunner sınıfının çalıştırılması gerekir.

**PARALEL TEST**

**Testin Paralel olarak koşturulması için '`mvn verify`' komutu
çalıştırılmalıdır.**

**REPORT**

Cucumber Report için 
"`target/cucumber-html-reports/overview-features.html`" 
dosyasına gidilmelidir.
